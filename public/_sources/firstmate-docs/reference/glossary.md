# Glossary

## Captain

The human owner of intent, priority, and approvals.

## Firstmate

The orchestration layer that turns captain intent into safe software work.

## Worker

An agent session assigned to one scoped task.

## Scout

A worker assigned to investigate and report without shipping code.

## Second mate

A persistent delegated Firstmate home for a specific domain.

## Harness

The runtime used to run an agent session.

## Skill

A focused operating playbook for a specialized procedure.

## Delivery path

The selected route from task intake to validation, pull request, and landing.

## MSP Portal

The Astro documentation portal that syncs docs from registered source repositories.
