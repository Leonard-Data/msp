# Tools

Firstmate uses external tools when they are the right owner for an action.

## Common tools

- Git and GitHub for source control and pull requests
- `gh-axi` for GitHub operations
- `no-mistakes` for guarded validation and review
- browser tools for UI inspection
- MSP Portal for publishing documentation sources

## Tool selection rule

Use the authoritative tool for the job.
Do not recreate GitHub, validation, or browser behavior in ad hoc scripts unless the existing tool cannot do the work.
