# Examples

## Create a documentation source for MSP

Captain asks:

```text
Create a private documentation repo from the MSP template and register it with MSP.
```

Firstmate should:

1. confirm outward-facing repo details if they were not explicit
2. create the private GitHub repository
3. seed it with the MSP documentation-source contract
4. add `.docs-source.yml` and small linked docs pages
5. register the source in MSP Portal `sources.yml`
6. run validation and build checks
7. report the registration pull request and any required approval
