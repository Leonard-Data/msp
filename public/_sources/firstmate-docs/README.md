# Firstmate documentation

Firstmate is the captain's operating layer for software work across projects.
It keeps the captain-facing conversation simple while coordinating project work, safety checks, validation, documentation, and follow-up.

## Fast path for readers

1. Read [Firstmate core and soul](concepts/firstmate-core.md) for the philosophy.
2. Read [Multi-project operations](concepts/multi-project-operations.md) for how one Firstmate coordinates many repositories.
3. Read [System map](architecture/system-map.md) for the architecture.
4. Read [Setup](guides/setup.md) to install or verify a home.
5. Read [Working well with Firstmate](guides/working-with-firstmate.md) to get better outcomes.
6. Use [Commands reference](reference/commands.md) when operating the system.
